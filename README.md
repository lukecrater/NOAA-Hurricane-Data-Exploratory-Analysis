# Hurricane Data Project

See [PROJECT_BRIEF.md](PROJECT_BRIEF.md) for the full brief and outline.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Usage

```bash
source .venv/bin/activate
python src/parse_hurdat2.py     # builds data/processed/hurdat2_clean.csv
python src/eda.py               # exploratory + explanatory EDA, figures 01-05
python src/features.py          # builds data/processed/hurdat2_features.csv
python src/model.py             # trains + CV-evaluates models, saves them to data/processed/models/
python src/ian_case_study.py    # applies the models to held-out Hurricane Ian, figures 06-07
python src/impact_layer.py      # storm-surge impact layer, figure 08
```

Each script depends on the previous one's output, so run them in order the
first time. `model.py` takes a few minutes (grid of RandomForests x 3 lead
times x 3 targets, cross-validated).

## Layout

```
data/
  raw/                     HURDAT2 source text + format docs (not modified)
    nhc_verification/      NHC's official forecast-error tables + Ian's Tropical Cyclone Report
  processed/                parsed/derived CSVs + trained models (regenerated by scripts, gitignored)
src/
  geo.py                    great-circle distance/bearing helpers
  parse_hurdat2.py           HURDAT2 text -> tidy DataFrame
  eda.py                     exploratory + explanatory analysis, figures 01-05
  features.py                lag/motion/intensity features + 24/48/72h targets
  model.py                   train + evaluate track/intensity models, benchmark vs. NHC
  ian_case_study.py          apply models to held-out Ian, figures 06-07
  impact_layer.py            storm-surge impact layer, figure 08
outputs/
  figures/                   generated PNGs
```

See [PROJECT_BRIEF.md](PROJECT_BRIEF.md) for the key results and known limitations.
